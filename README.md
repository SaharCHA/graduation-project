# Система рекомендацій відеоконтенту

Цей проєкт реалізує інтелектуальну систему рекомендацій відеоконтенту з використанням алгоритмів кластеризації (навчання без вчителя).

## Стек технологій
Відповідно до звіту з практики, використовується наступний стек:
- **Мова програмування:** Python
- **Обробка даних:** Pandas, NumPy
- **Машинне навчання:** Scikit-learn (K-Means, DBSCAN, Agglomerative Clustering)
- **Візуалізація:** Matplotlib
- **NLP (Обробка природної мови):** TF-IDF (з Scikit-learn) для векторизації текстів.

## Структура проєкту
- `data/raw/` - сирі дані (наприклад, метадані відео)
- `data/processed/` - очищені та нормалізовані дані
- `notebooks/` - Jupyter notebooks для експериментів та аналізу
- `src/` - вихідний код
  - `data/` - скрипти для завантаження та парсингу
  - `features/` - скрипти для підготовки даних (векторизація, нормалізація)
  - `models/` - алгоритми кластеризації та метрики
- `main.py` - головний файл для запуску пайплайну
- `requirements.txt` - залежності проєкту

## Запуск
1. Встановіть залежності: `pip install -r requirements.txt`
2. Запустіть головний скрипт: `python main.py`
